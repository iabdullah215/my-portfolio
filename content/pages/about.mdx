I work on application and system security, and I spend most of my own time on vulnerability research in the open-source infrastructure everyone else builds on. Self-taught, still learning in public, and happiest when something that was supposed to be safe turns out not to be.

The research side has produced CVEs and GitHub security advisories in [Gitea](https://github.com/go-gitea/gitea), [Wazuh](https://github.com/wazuh/wazuh), [Apple's Containerization](https://github.com/apple/containerization), [Better Auth](https://github.com/better-auth/better-auth), [Renovate](https://github.com/renovatebot/renovate) and [openapi-python-client](https://github.com/openapi-generators/openapi-python-client), along with fixes merged into [Caddy](https://github.com/caddyserver/caddy), [go-redis](https://github.com/redis/go-redis) and Wazuh, and an NSE script sent to [Nmap](https://github.com/nmap/nmap). The bugs are rarely exotic: a permission check that runs after the handler has already answered the request, an argument that reaches a shell unescaped, a cutoff date that excuses a cross-repository check, a brute-force limiter that counts sequentially while the requests arrive in parallel. Most of them came out of reading code rather than throwing traffic at it. The current list lives on [Contributions](/contributions).

My background is offensive — CPTS, CRTA, the HackTheBox Pro Labs, and a long run of CTFs where I mostly play pwn and reverse engineering. That is where the rest of the work comes from too: Active Directory tooling ([pathhound-mcp](https://github.com/iabdullah215/pathhound-mcp), [ActiveDecoy](https://github.com/iabdullah215/ActiveDecoy), [GPO-Audit](https://github.com/iabdullah215/GPO-Audit)), Android obfuscation internals, and AI red teaming. Anything I learn that is worth writing down ends up on the [blog](/blog).

I'm based in Islāmābād, doing an MS in Information Security at NUST alongside the day job. Always up for working with people who like breaking the same things I do.

## Projects

- [**DeepTrace**](https://github.com/iabdullah215/DeepTrace-IPDR): DeepTrace is an Internet Protocol Detail Record (IPDR) system that captures, parses, and visualizes network traffic data at flow level. It supports both offline PCAP file analysis and real-time packet capture, with a multi-layer security analysis engine capable of detecting 23 distinct attack types.
- [**pathhound-mcp**](https://github.com/iabdullah215/pathhound-mcp): An MCP (Model Context Protocol) server that lets an LLM reason over an Active Directory attack graph already collected by BloodHound — shortest paths to Tier 0, blast radius from a principal, the highest-leverage choke points to remediate, and defender-facing remediation text — with every action scoped to an authorized engagement and logged.
- [**ActiveDecoy**](https://github.com/iabdullah215/ActiveDecoy): An automated ITDR (Identity Threat Detection and Response) framework designed to orchestrate and deploy believable Active Directory honey-objects for proactive lateral movement detection.
- [**GPO-Audit**](https://github.com/iabdullah215/GPO-Audit): GPO-Audit audits Microsoft Group Policy Object (GPO) reports exported via Get-GPOReport (HTML or XML). It focuses on identifying common hardening gaps, risky delegation, and unresolved (orphaned) security principals, and it can export results and compare drift against a baseline.
- [**HeapHound**](https://github.com/iabdullah215/HeapHound): HeapHound is a Python-based tool built with my dear friend [Muhammad Munib](https://www.linkedin.com/in/muhammad-munib-nawaz-7b8129292/) and [Radeel Ahmed](https://www.linkedin.com/in/radeel-ahmad-866a50293/) for analyzing Java heap dump files (`.hprof`) to extract sensitive data, assess risks, and generate forensic reports. It identifies credentials, tokens, and other artifacts using built-in heuristics, producing reports in `JSON`, `HTML`, and text formats. Ideal for security investigations, malware analysis, and incident response.
- [**NetEye**](https://github.com/iabdullah215/NetEye): Net-Eye is an all-in-one Python-based network reconnaissance tool that detects live hosts, scans ports, grabs banners, resolves DNS, performs GeoIP lookups, and runs detailed Nmap scans. It also identifies known vulnerabilities based on discovered services, helping users assess and secure their networks effectively.
- [**hwatlib**](https://github.com/iabdullah215/hwatlib): A practical pentesting and exploitation python library with wrappers for recon, web enumeration, reverse shells, and privilege escalation.
- [**Blockchain Implementation**](https://github.com/mun1bxD/BlockChain): Developed a Java-based blockchain with features like user authentication, transaction tracking, and dynamic coin rate fluctuation. This project was a collaborative effort with [Muhammad Munib](https://www.linkedin.com/in/muhammad-munib-nawaz-7b8129292/), [Radeel Ahmed]
